## 📊 Algoritmo Explicado

### Convergencia Adaptativa

**Fórmula Base**:
```javascript
factor = initialFactor × (convergenceRate ^ iteration)
factor = 0.35 × (0.62 ^ iteration)
```

**Adaptación Dinámica**:
```javascript
// Si usuario elige consistentemente una dirección
if (últimas 3 elecciones = misma dirección) {
    factor *= 1.15  // Expande búsqueda +15%
}

// Si usuario usa "Es Igual"
if (elección = "igual") {
    factor *= 0.85  // Converge más rápido -15%
}
```

**Ejemplo Real**:

| Iteración | Factor Base | Usuario Elige | Factor Final | Rango |
|-----------|-------------|---------------|--------------|-------|
| 1 | 35.0% | Mayor | 35.0% | ±35% |
| 2 | 21.7% | Mayor | 21.7% | ±21.7% |
| 3 | 13.5% | Mayor | **15.5%** ⬆️ | ±15.5% (expandido) |
| 4 | 8.3% | Es Igual | **7.1%** ⬇️ | ±7.1% (acelerado) |
| 5 | 5.2% | Menor | 5.2% | ±5.2% |
| 6 | 3.2% | Menor | 3.2% | ±3.2% |
| 7 | 2.0% | Menor | 2.0% | ±2.0% |

**Resultado**: Sensibilidad perfecta con mayor confianza.

## 🎯 Cómo Usar

### Paso 1: Configuración Inicial

```
1. DPI del Mouse: 800 (verifica en software del mouse)
2. Sensibilidad Base: Ajusta en CS2 hasta hacer 360° con un swipe
3. Juego: CS2
4. Estilo: Rifler (o el que prefieras)
5. Aim Style: Mixed (o el que uses)
6. ✓ Modo Adaptativo: Activado
```

### Paso 2: 7 Iteraciones

**Para cada iteración:**

1. ⏱️ **Espera 30 segundos** (timer visible)
2. 🎯 **Prueba las 3 sensibilidades**:
   - Menor
   - Base
   - Mayor
3. 🔫 **Prueba en diferentes distancias**:
   - Largo (AWP shots)
   - Medio (sprays)
   - Corto (pistol rounds)
4. ✅ **Elige**:
   - **Prefiero Menor**: Si la más baja se siente mejor
   - **Es Igual**: Si no puedes decidir (acelera convergencia)
   - **Prefiero Mayor**: Si la más alta se siente mejor

### Paso 3: Resultado Final

**Recibirás:**

- ✅ **Sensibilidad Final**: 1.234
- 📊 **eDPI**: 987.2
- 📏 **cm/360°**: 42.5
- 🎯 **Consistencia**: 87% (Excelente)
- 🏆 **Comparación con Pros**: Más cercano a s1mple (+6.2%)
- 💡 **Análisis**: "Media: Equilibrio perfecto entre precisión y movilidad"

### Paso 4: Aplicar en CS2


## 💡 Tips para Mejores Resultados

### Antes del Cálculo

1. ✅ **Limpia tu setup**:
   - Mousepad sin polvo
   - Sensor del mouse limpio
   - Superficie plana y estable

2. ✅ **Desactiva aceleración**:
   - Windows: Panel de Control → Mouse → Desmarcar "Mejorar precisión"
   - CS2: `m_customaccel 0`, `m_mousespeed 0`, `m_rawinput 1`

3. ✅ **Usa tu DPI nativo**:
   - Logitech: 400, 800, 1600
   - Razer: 400, 800, 1600, 3200
   - SteelSeries: 400, 800, 1200, 1600

### Durante el Cálculo

1. ⏱️ **Respeta el timer**: Espera los 30 segundos completos
2. 🎯 **Prueba en bots**: No en competitivo
3. 🔄 **Haz múltiples pruebas**: Tracking, flicks, sprays
4. 💭 **Confía en tu instinto**: Elige lo que se siente cómodo, no lo que "debería" ser

### Después del Cálculo

1. ⏰ **Compromiso**: 2-3 semanas mínimo sin cambios
2. 🎮 **Practica diario**: 30min de aim training
   - Aim Botz (10min)

3. 📊 **Trackea tu progreso**: Anota stats (HS%, K/D)
4. 🚫 **No cambies**: Resiste la tentación de ajustar

## 🐛 Troubleshooting

### "Mi score de consistencia es bajo (<50%)"

**Causas**:
- Te apresuraste (< 15s por iteración)
- Alternaste mucho entre opciones
- No probaste adecuadamente

**Solución**:
- Repite el cálculo
- Tómate el tiempo completo (30s)
- Confía más en tus instintos

### "Mi sensibilidad está fuera del rango recomendado"

**Es normal si**:
- Tienes un estilo único
- Usas un mousepad muy grande/pequeño
- Vienes de otro juego

**Recomendación**:
- Pruébala 1 semana
- Si te sientes incómodo, repite PSA
- Considera ajustar tu hardware (mousepad más grande, etc.)

### "No puedo decidir entre las opciones"

**Usa "Es Igual"**:
- No tiene penalización
- Acelera la convergencia
- Indica que estás en el rango correcto
